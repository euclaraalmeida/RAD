# RELATORIO

## 1. Qual a diferença prática entre projeto e app?

O projeto é a aplicação inteira e o app é uma parte do projeto em específico e independente.

## 2. Por que a pasta `.venv` não deve ser versionada?

Contem o ambiente virtual es dependencias instaladas como pode ser recriada várias vezes nao precisa ser versionada.

## 3. O que acontece quando um conversor `int` recebe um texto na URL?

Só vai aceitar apenas números e vai converter para inteiro.

## 4. Por que os dados criados pelo endpoint POST desapareceram após o reinício?

Porque os dados estavam em memória.
